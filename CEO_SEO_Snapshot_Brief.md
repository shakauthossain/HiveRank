# SEO Snapshot Tool

**For:** Leadership  
**From:** Technology  
**Date:** 18 August 2026  
**Ask:** Approve a $50 prepaid data top-up so we can build this.

---

## 1. The ask

Sales wants a short Notionhive-branded SEO audit they can send a prospect.

Input: the prospect’s website + one competitor.  
Output: an 8–10 slide deck. A person reviews every deck before it goes out.

**Recommendation: go.** Cost is not a blocker.

---

## 2. Feasibility

This is doable with what we already have.

- We already have an internal web app and Google’s **free** page-speed check.
- We **buy** the SEO numbers (estimated traffic, keywords, site health, competitor gap) from one data vendor. Prepaid credits — not a new monthly software seat.
- A **person reviews every deck** before it is sent. Nothing goes out automatically. No AI writing the story.
- Tiny or new websites often have little keyword data. In that case we drop those slides and show more technical findings. The deck still goes out.
- This is a **sales leave-behind**, not a public product. Staff login only.

No extra headcount to run it.

---

## 3. Cost

| | Amount |
|---|---|
| One deck | ~$0.15 |
| 20 decks per month | ~$3 |
| To start | $1 free trial, then **$10 prepaid** |
| How long $10 lasts | about **2 months** at this volume |
| Google page-speed data | $0 |
| Monthly subscription | none |

The $50 is a balance we spend down. It is not a monthly fee.

The only way cost jumps is if we pull too much data per site (up to ~$0.50). We cap that in the tool and in the vendor’s daily spend limit.

---

## 4. Process

1. Operator types the prospect site and one competitor.
2. The tool pulls the data (a few minutes).
3. A person checks the numbers, edits the “top 5 fixes,” and approves.
4. Download the branded deck and send it.

---

## 5. Decision

Approve the **$10** top-up when we leave the $1 trial. Set a daily spend cap. Then engineering builds.

No monthly subscription. No extra headcount.
